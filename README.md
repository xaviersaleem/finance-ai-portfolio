# Finance AI & Analytics Portfolio

Selected finance automation and business intelligence work, ranked by the blend of finance role relevance, practical business use, and current demand for data, systems, planning, and AI-enabled workflow skills.

The archive contained many overlapping tutorial exercises. This repository includes two of the most complete, differentiated examples. Tutorial prompt PDFs and local dependency/cache files are omitted. All included companies and financial data are fictional examples for portfolio demonstration; do not use these prototypes for real financial decisions without independent validation.

## Selected projects, in priority order

### 1. Finance Operations Decision Support Team — new

A role-based workflow for a finance analyst, FP&A strategy partner, and CFO advisor. Includes Python scripts for store performance analysis and expansion business cases, supporting methodologies, sample workbooks, and a board recommendation pack.

**Skills:** FP&A, Python, pandas, Excel automation, investment analysis, executive reporting, AI-assisted finance workflows.

[Open project](finance-operations-decision-support/)

### 2. CFO Dashboard in Power BI — new

An interactive CFO reporting prototype spanning financial performance, growth and retention, profitability and cost, and cash outlook. Includes the Power BI Project (PBIP), report definition, semantic model, and synthetic source workbook.

**Skills:** Power BI, semantic modeling, TMDL, financial analytics, dashboard design, executive reporting.

[Open project](cfo-powerbi-dashboard/)
