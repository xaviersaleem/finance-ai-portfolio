# CFO Dashboard in Power BI

A CFO-focused Power BI report prototype with pages for financial performance, growth and retention, profitability and costs, and cash outlook.

## Files

- `dashboard.pbip` — open the Power BI Project in Power BI Desktop.
- `dashboard.Report/` — report pages, visuals, bookmarks, and formatting.
- `dashboard.SemanticModel/` — model definition and measures.
- `TitanFlow_CFO_Dashboard_Data.xlsx` — fictional source workbook.

## Use

Open `dashboard.pbip` in a recent Power BI Desktop release. If Power BI prompts for a source location, point it to the included workbook. The PBIP project may require refresh in Power BI Desktop before the report renders; no published Power BI Service link is included.

## Disclosure and attribution

This is a portfolio prototype based on fictional sample data, not a live company dashboard. The source archive included AI Finance Community tutorial materials; their PDFs and prompt packs are not redistributed here. Verify report calculations and refresh behavior before relying on any figures.
