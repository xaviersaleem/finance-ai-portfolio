# Finance Operations Decision Support Team

A fictional case study showing how finance analysis, FP&A strategy, and CFO review can work as a coordinated, role-based workflow.

## What is included

- Finance Analyst materials and a Python script for flexible store-performance analysis.
- FP&A Strategy Partner materials and a Python script for expansion business-case analysis.
- CFO Advisor materials and a Python script for assembling a board recommendation pack.
- Synthetic source workbooks, sample analytical outputs, and a board presentation.

The scripts produce structured analysis outputs; the role guidance supports interpretation and management communication. This is a portfolio prototype, not a production autonomous agent system.

## Run the analysis scripts

Install Python 3 and the script dependencies (`pandas`, `numpy`, and `openpyxl`). Each script documents its input and output options near the top of the file. Example:

```bash
python "Workers/Finance Analyst/scripts/build_store_analysis.py" --input "Source Data/Current_Store_Performance.xlsx" --output "Worker Outputs/Store_Analysis_Report.xlsx"
```

The other scripts have their own arguments and output formats. Run them only with the supplied fictional sample data or another dataset you are authorized to use.
